# Platinum Mod (铂金模组)

> **模组名称**: Aev Mod  
> **模组版本**: 1.0.3  
> **Minecraft 版本**: 1.16.5  
> **Forge 版本**: 36+  
> **模组ID**: aevmod

---

## 模组简介

Platinum Mod 是一个以**铂金**为核心主题的综合内容模组，为 Minecraft 1.16.5 添加了完整的铂金工艺体系，包括矿石生成、全套工具与装备、建筑装饰方块、特殊容器、自定义画作、音乐唱片以及世界结构等丰富内容。

---

## 主要特性

### 铂金矿石与材料
- **铂金矿石** - 在主世界地下生成，需要铁镐或更高级的镐开采
- **铂金锭** - 基础合成材料
- **铂金粒** - 用于精细合成

### 铂金工具
全套铂金工具，性能优异：
- 铂金剑
- 铂金镐
- 铂金斧
- 铂金锹
- 铂金锄

### 铂金装备
- **铂金头盔**
- **铂金胸甲**
- **铂金护腿**
- **铂金靴子**
- **铂金马铠** - 保护你的坐骑

### 建筑装饰方块
完整的铂金建筑方块系列：
- 铂金块
- 铂金楼梯
- 铂金台阶
- 铂金栅栏
- 铂金栅栏门
- 铂金按钮
- 铂金压力板
- 铂金门
- 铂金活板门

### 特色容器
- **铂金箱子** - 9x9 大型储物空间
- **铂金箱子 II** - 10x10 超大储物空间
- **便携箱子** - 可随身携带的移动储物工具(可搭配潜影盒使用)

### 特殊物品
- **若水 (Aqua Simulacra)** - 特殊弓类武器(特性暂时未写)
- **铂金唱片** - 可播放音乐的唱片(MAdEaR)
- **装饰画作** - 可放置的画作(GenShin 1.0)

### 世界生成
- **铂金矿石** - 在主世界地下自然生成
- **机密银行结构** - 稀有的世界生成建筑，内含战利品

---

## 安装说明

1. 确保已安装 **Minecraft 1.16.5** 和对应版本的 **Forge**
2. 将模组 `.jar` 文件放入 `.minecraft/mods` 文件夹
3. 启动游戏即可游玩
